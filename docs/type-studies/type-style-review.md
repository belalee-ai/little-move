# 字体样式复核与接入说明

复核日期：2026-10-15。范围：当前 17 个英文动效示例。

依据为用户提供的截图、原始 MOV 中的可见字形，以及此前保存的参考关键帧。IMG_1999–IMG_2014 目前位于 `原参考素材目录（未随仓库分发）`。字体名称与作者的原始制作方法未经确认，以下记录可观察的样式与本地重建方法，不把替代字形说成原字体。

## 本次纠正

之前主要重建了运动，多个预览过度复用了同一套粗无衬线字体，尤其丢掉了 IMG_2007 的像素阶梯轮廓。字体轮廓、字腔、字宽、端点、大小写、填充、描边与负形应当分别核对，不能只匹配运动速度。

| 示例 | 参考中可见的字体特征 | 当前实现与复核结果 |
|---|---|---|
| 文章可变字体 | 干净无衬线；字重、倾斜与笔画比例变化 | 保留多轴变化，使用替代可变字体；未确认原字体名称 |
| IMG_9551 字母重组 | 厚实标题字，不同字的大小、高低和倾斜变化 | 保留关键词字形与逐字排版；英文替代样字，不统一像素化 |
| IMG_2001 混排 | 文字与细线图形、卷带形成整体构图 | 保留 Just one more IDEA；深色底与米白字，IDEA 逐字衬线、无衬线和描边混排，固定字高与词组总宽，遮罩逐字换形；按用户反馈移除无信息作用的折带与纸环，两级标题收紧对齐并保留错拍落位及分组退出 |
| IMG_1999 字环 | 常规字重、大小写随路径编排 | 保留常规字重与已有圆形路径核心；原片中心为人物画面，本版原纯色圆占位已换成独立设计的金属三叶环结。使用实时立体网格与固定空间光照，循环翻转；文字分前后两层绘制 |
| IMG_2002 字标重组 | 圆润小写字标，圆角端点和开放字腔 | 按最新反馈替换碎片分散：保留完整 bloom 字形，用户已选定波浪展开，作为默认预览和网站集成版本；弹性聚拢、翻转落位保留为备选。约一秒归位，完整态与字腔一致；已移除随机笔画切片与散飞。 |
| IMG_2003 人物穿字 | 饱满圆润标题、浅色填充和白描边 | 使用 IMG_0278 真人抠图，保留抬手姿势；背景为暖白，SUMMER 改为蓝色实心字与细白描边。实心字在后、人物居中、描边字在前；字形与文字动作一致，照片等比移动及轻微缩放 |
| IMG_2004 贴字 | 综艺感厚字，浅色字面、清晰深色外沿 | 使用 IMG_0278 真人抠图；主词更大、字重 610–660，改为珊瑚色与深蓝字面、细深色字沿及白色裁切边，保留字腔；四组文字错拍弹入，避开人物脸与手 |
| IMG_2005 空间折叠 | 高而窄的字面，字在墙面和地面保持连续 | 保留纵向拉长的字面与连续投影；IMG_0278 真人抠图作为右下半身前景，独立于墙地折叠层，避免缺少脚部的照片悬在地面上，保持主要折线与文字可见 |
| IMG_2006 叠贴 | 多种独立字标：像素块、圆角、衬线、卷曲、窄体并存 | 分别设置像素格点、较轻圆角无衬线、粗细反差衬线与卷曲装饰；不再全部使用同一粗黑体 |
| IMG_2007 快切海报 | 阶梯像素字形；黑白横线条带；棋盘格 | 以明确的字母格点矩阵重建字形，字边是实际阶梯轮廓；条带和棋盘格独立绘制，保留整版快切 |
| IMG_2008 像素笔画 | 相连的像素笔画，字腔与肩部轮廓换形 | ABCDEF 使用相连的定制笔画骨架，在固定细网格上连续改变粗细与字腔；格间仅保留细缝，边缘格渐进过渡，取消三档粗细跳变。与 2014 的独立点阵分开处理 |
| IMG_2009 弧线字组 | 常规黑字、独立浅色小底形、大小写混排 | 保留现有普通字形；背景按用户反馈由灰紫改为钴蓝 #2555df，独立字块为浅白 #f7f8f2，深色字保持清晰；运动、字号和路径不变 |
| IMG_2010 几何字标 | 字内多色几何模块、圆孔、三角形和点纹 | MOTIFS 中加入字内分色、镂空与点纹。原录像为静态；当前拼合动画是新增创作 |
| IMG_2011 节拍器 | 细长字杆、圆润端点、上细下粗，底部稳定 | Sway 使用定制曲线及随高度改变的笔画宽度；钟体改为摄影质感的木质指针与拉丝金属摆锤，偏右构图、暖色墙面与侧光投影；摆锤与各字形连续往返。钟体为 imagegen 生成的透明素材，摆杆与摆锤在动画中独立旋转 |
| IMG_2012 首字母 | 轻字重无衬线；T、S、f 的首笔有独立手势 | T / S / f 使用独立矢量笔画，S 去掉原来的 Georgia 衬线；词尾维持较轻字重 |
| IMG_2013 缩写重排 | 大小写组合、不同字宽；并非全大写极粗字 | 改为 ForM 大小写组合，降低整体字重，保留每字不同位置、大小和角度；收回后 Fold / Observe / Rotate / Mix 按各自对应字母的中心分列对齐，逐字显示时使用完整单词宽度固定起点 |
| IMG_2014 反向字带 | 点阵、衬线、细线断笔、圆润切割和窄体分组出现 | 分别绘制点阵、细线中断、圆润切割等状态；保留分行换字体，不用一种通用字体包办 |

## 接入“动效词典”时必须保留

- 当前预览入口：`type-motion-lab.html`。
- 当前实现源文件：`english-type-motion.html`、`expressive-type-motion.html`、`six-type-studies.html`、`nine-type-studies.html`。
- `six-type-paths.json` 已同步为当前 bloom 圆角样字轮廓。
- 像素矩阵、矢量轮廓、变宽字杆、点阵与切割遮罩都是效果内容，接入时保留各自渲染方法；不能统一替换成网站的默认粗体。
- 英文样字继续与参考作品及本项目其他示例区分。替换文字时须重新检查字宽、字腔、描边、分行和安全边界。
- 本次只更新当前预览与字体样式记录，没有修改另一个对话的网站工程，也没有导出成片或公开发布。
